Why akakce-mcp?

Akakçe uses Akamai Bot Manager to block conventional programmatic requests. Here is how akakce-mcp delivers seamless, zero-ban price comparisons for AI agents.

🛡️

Akamai Defense Bypass

Node fetch gets TLS-fingerprinted and returns 403 Forbidden. akakce-mcp channels requests via system curl with authentic iOS / Chrome headers to guarantee 100% request success.

⚡

Multi-Seller Comparisons

Retrieves all sellers on one screen: Amazon TR, Hepsiburada, Trendyol, PttAVM, idefix, Teknosa. Delivers prices, shipping costs, store ratings, and direct checkout outbound links.

🔔

Wishlists & Price Alerts

Manage favorite lists, trigger automatic price drop alerts when products fall below target thresholds, and query active notifications without opening a browser.

Authentication & Token Extraction Guide

Public search, pricing, and category tools require zero credentials. For account features (favorites, price alerts), choose any of the three secure methods below:

Method 1: Interactive Terminal Login (Easiest)

Run the built-in authentication wizard. Your session cookie is stored locally at ~/.config/akakce-mcp/session.json (chmod 0600) and is valid for ~1 year:

npx akakce-mcp auth

Enter your Akakçe email and password. The token is fetched directly from api6.akakce.com without any intermediate servers.

Method 2: Extract Cookie from Browser (DevTools)

If you log in via Google/Apple or prefer not to type your password:

  1. Log in to akakce.com in your browser.
  2. Open DevTools (F12 or Cmd+Opt+I) → Application → Cookies → https://www.akakce.com.
  3. Find the cookie named AAATLGST and copy its value.
  4. Save it with one terminal command:
npx akakce-mcp set-cookie "AAATLGST=your_copied_value"

Method 3: Environment Variable (CI/CD & Docker)

Supply your cookie or login credentials directly in your environment:

# Option A: Direct Session Cookie
export AKAKCE_COOKIE="AAATLGST=..."

# Option B: Automated Login Credentials
export AKAKCE_EMAIL="user@example.com"
export AKAKCE_PASSWORD="your-password"

Alternatives & Comparison

How akakce-mcp compares to other Turkish ecommerce data collection methods and tools.

vs. Direct Puppeteer / Scraper

Traditional scraping with Cheerio or headless Chrome is slow (2-5s per request), memory intensive (>300 MB), and immediately triggers Akamai's anti-bot JS challenges (HTTP 403). akakce-mcp connects directly to the underlying JSON API via system curl in ~150ms.

vs. Cimri.com Scrapers

Cimri lacks programmatic user wishlist manipulation, notification counters, and persistent price drop alarms. akakce-mcp covers both public search and authenticated private actions (favorites, target price alerts).

vs. Google Shopping / SerpAPI

Commercial SERP APIs charge steep monthly subscription fees ($50-$200/mo) and often return delayed or incomplete merchant listings for Turkish regional sellers. akakce-mcp is 100% free, open-source, and retrieves real-time pricing.

Frequently Asked Questions

Answers to common questions about running akakce-mcp with Claude Code, Cursor, and AI agents.

How do I use akakce-mcp with Claude Code?

Run claude mcp add akakce -- npx -y akakce-mcp. Claude Code will automatically register all 20 tools and connect via the standard stdio protocol.

Does akakce-mcp bypass Akamai bot protection?

Yes. Akakçe uses Akamai Bot Manager which blocks standard Node.js fetch with HTTP 403 Forbidden. akakce-mcp routes requests through system curl with authentic browser and mobile headers to bypass TLS fingerprinting.

Do I need an Akakçe account or API key to search prices?

No. All product search, multi-seller comparison, and category browsing features work out-of-the-box with zero credentials and zero API keys.

How do I extract my session token for price alerts?

You can run the interactive terminal login via npx akakce-mcp auth, extract the AAATLGST cookie from browser DevTools via npx akakce-mcp set-cookie, or set the AKAKCE_COOKIE environment variable.

How does akakce-mcp compare to direct web scraping?

Direct web scraping is fragile, resource-heavy, and frequently triggers IP bans. akakce-mcp connects directly to the underlying api6.akakce.com JSON APIs, delivering fast, structured JSON data with zero browser overhead.
